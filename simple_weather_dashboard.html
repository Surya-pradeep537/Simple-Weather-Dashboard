ℹ️ About This Project

This Simple Weather Dashboard is developed using HTML, CSS and JavaScript. It retrieves weather information from the free Open-Meteo API and displays current conditions, hourly forecast, 5-day forecast and air-quality information.

No API key required. An active internet connection is required. Browser location access may require HTTPS or localhost.
